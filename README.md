# Suprinval · Materiales Eléctricos

Web estática (HTML + imágenes). Se publica en Vercel sin configuración: Framework Preset "Other", sin build command.

- `index.html` – la página completa (catálogo, pedidos, asesoría, contacto)
- `img/productos/` – fotos del catálogo (fondo blanco, 260×260)
- `img/fotos/` – fotos de portada y sectores (Unsplash, licencia libre)
- Para editar el catálogo: buscar `const TOP` (más pedidos) y `const P` en `index.html`
